# 右鍵功能與模擬範圍

所有頁面攔截瀏覽器原生右鍵。下列選單只操作這套玩具的介面／文件；不是作業系統桌面或真正的視窗管理員。Angel背景、圓尺、人形、資料區、列表及區域按鈕不另開右鍵選單；原有檔案四項子選單不增項。

| 區域 | 項目 | 實際處理 | 範圍判斷 |
| --- | --- | --- | --- |
| XP桌面／工作列 | Angel Player を開く | 顯示／還原Angel工作區 | 實際玩具介面操作 |
| XP桌面／工作列 | 最新の情報に更新 | 更新畫面時鐘，不重新載入入口 | 模擬桌面更新，不更新OS桌面 |
| XP桌面／工作列 | ログオフ | 沿用草稿確認後回登入 | 模擬系統登出 |
| XP桌面／工作列 | 終了オプション | 原生關App，HTML切結束畫面 | 只結束玩具，不關機OS |
| Angel標題列 | Minimize／Close | 回XP桌面／處理草稿後關工作區 | 模擬App視窗 |
| 編輯器標題列 | Restore／Maximize／Close | 限右側編輯範圍還原／最大化／隱藏 | 不重新加入已移除的最小化 |
| 文字區 | Undo／Redo | 20步內容與選取復原／重做 | 實際編輯操作，無歷史時停用 |
| 文字區 | Cut／Copy／Paste | 使用瀏覽器剪貼簿許可，拒絕時顯示錯誤 | 實際剪貼簿，只在使用者選取時呼叫 |
| 文字區 | Delete／Select All | 修改選取文字／選取全文 | 實際編輯操作 |
| 文字區 | Save／Save As | 既有原生或IndexedDB儲存 | 實際保存內容，沒有新增格式 |

不提供真實系統的工作管理員、解析度設定、磁碟管理、檔案總管或程式執行。這些功能超出模擬環境，不能以有作用的按鈕假裝可用。

選單依游標位置限制在可見範圍，滑鼠外點／Escape／resize／idle收起；方向鍵巡覽，無效項停用。App存檔對話框另使用相同黑藍配色，標題可拖曳。
